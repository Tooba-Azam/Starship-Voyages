# 🎮 Game Modes

## Arcade Mode
A structured three-level campaign. Each level begins with continuous enemy waves and ends with a unique boss battle. Defeat all three bosses to win the game.

## Survival Mode
An endless wave-based mode with no bosses. Survive as long as possible and chase the highest score. Difficulty scales with every wave:

---

# 👾 Enemy Types

| Enemy | Description |
|-------|-------------|
| Drone | Moves straight down, fires at random intervals |
| Viper | Descends in a sine-wave pattern, harder to dodge and hit |
| Seeker | Locks onto the player's position and attacks aggressively |

---

# 💀 Bosses (Arcade Mode Only)

### The Cruiser - Level 1
- Sweeps left and right across the screen
- Fires a horizontal wall of bullets with one safe gap
- Speeds up in Phase 2 (below half health)

### The Twin Cannons - Level 2
- Central immune core flanked by two independent turrets
- Core cannot be damaged until both turrets are destroyed
- Each turret aims at the player's current position
- Core fires aimed bullets once exposed

### The Mothership - Level 3
- Periodically spawns Seeker enemies mid-fight
- Fires a full screen-width laser with a 1-second warning flash
- Spawns seekers more frequently and fires laser faster in Phase 2

# ⚔️ Weapons & Power-Ups

Players start with the Standard Shooter. Defeated enemies rarely drop weapons or defense upgrades.

| Power-Up | Effect |
|---|---|
| **Spread Module** | Fires three bullets in a forward fan |
| **Piercing Module** | Single beam, double damage, passes through enemies |
| **Energy Shield** | Absorbs 2 hits before breaking, resets on re-collect |
| **EMP Nuke** | Instantly destroys all enemies on screen, deals heavy damage to boss. Max 3 held |
| **Evasive Dash** | Teleports the ship a short distance in the direction currently moving |

- C++17
- SFML 2.6.x

Compile the project and ensure the **Assets** folder is placed alongside the executable.

# 🌟 About

**Starship Voyages** is a fast-paced 2D arcade shooter developed from scratch in **C++** using **SFML**. The game combines strategic combat, diverse enemy behaviors, challenging boss battles, and responsive controls to deliver an engaging space shooter experience while demonstrating advanced game development concepts.
